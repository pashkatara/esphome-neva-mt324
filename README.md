## 📖 О проекте

Данный проект позволяет напрямую и без использования оптических головок (оптопар) считывать точные данные со счётчика электроэнергии **Нева МТ 324** через клеммы интерфейса **RS-485 (EIA-485)** и передавать их в **Home Assistant** (включая встроенную панель **Energy Dashboard**).

## ✨ Возможности

- 🔌 **Надёжное проводное подключение** по витой паре (RS-485).
- 📊 **Трёхфазные мгновенные показания:**
  - Напряжение по каждой фазе: $L_1, L_2, L_3$ (В).
  - Сила тока по каждой фазе: $L_1, L_2, L_3$ (А).
  - Суммарная активная мощность (Вт).
- 💰 **Показания тарифов:**
  - Энергия $T_1$ (День / Пик), кВт⋅ч.
  - Энергия $T_2$ (Ночь), кВт⋅ч.
  - Суммарная потреблённая энергия (Всего), кВт⋅ч.
- 🔐 **Автоматическая авторизация** и обмен стартовыми пакетами (Handshake IEC 62056-21).
- 🏠 **Полная совместимость с Home Assistant Energy Dashboard**.

## 🔌 Поддерживаемые счётчики

- **Нева МТ 324 AR 1.0** (протестировано)
- **Нева МТ 314 / Нева МТ 323** и другие модели с поддержкой протокола обмена ГОСТ Р МЭК 61107 / IEC 62056-21 (OBIS-Z) через встроенный RS-485.

---

## 🛠 Необходимое оборудование

1. **Микроконтроллер:** ESP32 (рекомендуется) или ESP8266.
2. **Преобразователь UART-TTL в RS-485:**
   - Модуль с **автоматическим определением направления** (Auto Direction Control, рекомендуется) или классический MAX485 / MAX3485.
3. **Блок питания:** 5V / 3.3V для ESP32.
4. **Витая пара / провод:** для подключения к клеммам A+ и B- счётчика.

## 📐 Схема подключения (Wiring)

### Клеммы интерфейса на счётчике «Нева МТ 324»:
- **A+** — Прямой дифференциальный сигнал линии RS-485.
- **B-** — Инверсный дифференциальный сигнал линии RS-485.

### Таблица соединений:

| ESP32 Пин | Модуль RS-485 (TTL) | Счётчик «Нева МТ 324» | Примечание |
| :--- | :--- | :--- | :--- |
| **GPIO 5** (TX) | **DI** (Data In) | — | Передача данных в RS-485 |
| **GPIO 4** (RX) | **RO** (Receiver Out) | — | Приём данных из RS-485 |
| **5V / 3.3V** | **VCC** | — | Питание модуля |
| **GND** | **GND** | — | Общий провод |
| — | **A+ (A)** | **Клемма A+** | Линия данных A |
| — | **B- (B)** | **Клемма B-** | Линия данных B |

> 💡 **Примечание:** Если вы используете модуль с аппаратным автоматическим переключением направления (Auto-flow), контакты `DE` и `RE` подключать не требуется. Если модуль ручной — замкните `DE` и `RE` на отдельный свободный GPIO для программного управления.

## 🚀 Быстрый старт и установка

1. Склонируйте репозиторий или скачайте файл конфигурации:
   ```bash
   git clone https://github.com/pashkatara/esphome-neva-mt324.git
   ```

2. Откройте **ESPHome Dashboard** в Home Assistant (или используйте ESPHome CLI).

3. Создайте новое устройство или скопируйте файл [`neva-mt324.yaml`](neva-mt324.yaml) в директорию конфигураций ESPHome.

4. Настройте блок `substitutions` или секреты в `secrets.yaml`:
   ```yaml
   wifi_ssid: "Ваша_WiFi_Сеть"
   wifi_password: "Ваш_Пароль_WiFi"
   ```

5. Выполните компиляцию и прошивку на ESP32.

6. В Home Assistant перейдите в **Настройки → Устройства и службы** — устройство определится автоматически через нативную интеграцию **ESPHome**.

## 📊 Добавление в панель Энергии (Home Assistant)

Перейдите в Home Assistant в меню **Настройки → Панели управления → Энергия**:
1. В блоке **Потребление из электросети** добавьте:
   - `Энергия Т1` (Дневной тариф)
   - `Энергия Т2` (Ночной тариф)
   *(или `Энергия Всего`, если тариф одноставочный)*
